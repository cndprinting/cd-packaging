Folding Table — What It Is and Why We Need It
What is the folding table?
The folding table is a set of rules that tells the estimating system how a printed sheet will be folded, what machine can do it, how long it should take, and what it should cost.
The system should be able to look at a quote and say:
“This job requires a letter fold on the MBO. The paper is 80# text, the quantity is 25,000, setup is X minutes, production speed is Y sheets/hour, therefore folding time is Z.”
Without a folding table, the computer doesn't really know how we actually produce the job.
________________________________
Why We Need It
A commercial printing estimate has several major components:
Paper → Printing → Cutting → Folding → Finishing → Packaging
We are working on the Folding portion.
The folding table allows the estimating program to turn your production knowledge into repeatable rules.
For example:
A CSR enters:

  *   Quantity: 25,000
  *   Flat size: 11 × 17
  *   Finished size: 8.5 × 11
  *   Paper: 80# text
  *   Fold: Letter fold
The system looks at the tables:
Paper Table
80# text → approximately 5 mil
⬇️
Folding Table
Letter fold + 5 mil + MBO → appropriate production speed
⬇️
Machine Table
MBO → setup and running parameters
⬇️
Estimate
25,000 sheets → calculated folding hours → folding cost

The Most Important Part
Do not make the folding table just a list of folding speeds.
It needs to describe the entire production process.
For example:
Letter Fold
Input:
11 × 17 sheet
80# text
25,000 sheets
System determines:

  *   Fold type = Letter
  *   Machine = MBO
  *   Number of folds = 2
  *   Setup time = predetermined
  *   Running speed = predetermined
  *   Waste = predetermined
  *   Scoring = No
  *   Production time = calculated
Basic Formula
Folding Run Time = Quantity ÷ Running Speed
Then:
Total Folding Time = Setup Time + Run Time + Allowances
And finally:
Folding Cost = Total Folding Time × Machine/Labor Rate

How We Should Build It
I recommend we don't try to fill in 50 different folds at once.
We'll build it in this order:
Step 1 — Common folds

  *   Half fold
  *   Letter fold
  *   Tri-fold
  *   Double parallel
  *   Right-angle
Step 2 — Specialty folds

  *   Open gate
  *   Closed gate
  *   Accordion
  *   8-page configurations
  *   12-page configurations
Step 3 — Machine information

  *   MBO B306/4/4
  *   MBO 4/4/4
  *   Other folders you use
Step 4 — Paper interaction
Connect the folding table to the caliper table we just discussed.
Step 5 — Cost calculation
Connect setup, speed, waste, labor and machine rates.
