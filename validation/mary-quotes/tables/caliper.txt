6. Rules the Estimating System Should Use
The system should not make folding decisions from paper name alone.
The calculation should be:
Paper Selection → Actual Caliper → Fold Type → Machine → Machine Capability → Production Rule
For example:

  *   Thin text stock → normal folding
  *   Heavier text stock → check folding configuration
  *   Cover stock → check scoring requirement
  *   Heavy cover → scoring normally required before folding
  *   Very heavy stock → check machine maximum
  *   Stock beyond machine capability → flag for estimator review
7. Critical Database Rule
If the actual paper supplier provides a caliper, use the supplier's actual caliper instead of the default table value.
Example:
18 pt C1S
Default database value: 18 mil
If the mill specification says the actual caliper is 17.2 mil, the system should use 17.2 mil for machine and finishing calculations.

Final instruction for the programmer
Do not hard-code folding or scoring decisions into the paper table.
Keep these as separate databases:

  1.  Paper Master
  2.  Paper Caliper
  3.  Machine Capabilities
  4.  Fold Types

The estimating engine should use these tables together to determine the correct production method and cost.
